科学中药进销存 App 修改日志
版本：v3
日期：2026-10-29

本次修改
1. 进货入库的药品栏新增搜索输入框，可用中文药名、完整拼音或拼音首字母筛选。
   示例：茯苓可输入“茯苓”、“fuling”或“fl”；黄芪可输入“huangqi”。
2. 药品资料库搜索同步支持完整拼音及拼音首字母。
3. 对重名药品，在进货选项中额外显示药品编号，便于区分相同名称的记录（例如重复的安中散）。
4. 旧版浏览器本机资料会依药品编号补齐原始清单的拼音索引，尽量保留既有库存、进货及调剂记录。
5. 在资料备份页面增加本次版本更新日志。

保留功能
- 药品资料、药品类别与自定义类别
- 药物归经字段
- 进货入库、批次库存、调剂及异动记录
- JSON 完整备份与恢复、CSV 药品资料导出

注意事项
- 拼音由系统转写生成，少数药名、异体字或多音字可能需要人工核对。
- 本版本仍为浏览器本机储存，不代表已实现云端同步。
- 发布到 GitHub Pages 时，请先备份当前线上文件与浏览器资料，再以本档案内容覆盖仓库中的 index.html。
